# Обновления «Ю»

Начиная с 0.6.0 приложение проверяет новые версии на главном экране не чаще раза в сутки. Проверка не открывает окна поверх серий. «Позже» закрывает предложение до следующей проверки; ручная проверка доступна в настройках. Автопроверку можно выключить.

После нажатия «Обновить» приложение повторно проверяет выпуск, показывает ход загрузки, проверяет SHA-256, имя пакета, номер версии и совпадение подписи с установленным APK. Затем открывается системное подтверждение Android. Если приложение ушло в фон, установка ждёт возвращения в настройки. При первом обновлении Android может попросить разрешить установку из «Ю».

Версию 0.6.0 нужно один раз установить вручную поверх прежней версии. Не удаляйте приложение: история просмотра и настройки сохраняются при обновлении с прежней подписью.

Источник по умолчанию:
`https://raw.githubusercontent.com/Sqzzzzzzz/utv-android-tv-updates/main/release.json`

В настройках можно указать другой HTTPS-источник; пустое поле возвращает GitHub по умолчанию. Токен GitHub в APK не нужен и не используется. Ошибки ручной проверки отображаются в настройках. Сбой автопроверки не мешает просмотру.

## Публикация будущих версий

Исходники остаются в закрытом `utv-android-tv`. Публичный `utv-android-tv-updates` содержит подписанные APK, метаданные и сценарий публикации. Для следующего выпуска:

1. Увеличить versionCode и versionName, выполнить сборку, тесты, lint и независимую проверку.
2. Собрать APK прежним ключом. Сборка с `-Putv.ci=true` использует другой ключ и не подходит для установки поверх версии владельца.
3. Добавить части готового APK в отдельную ветку публичного репозитория и обновить `publication.json`: версия, SHA-256, SHA частей и описание. Ключи и исходники туда не загружать.
4. Workflow проверит пакет, версию, сертификат и SHA-256, опубликует APK в Releases, скачает его повторно для проверки и только после этого обновит `release.json`.

Действующий опубликованный APK не перезаписывается. Каталог не может откатиться на меньший versionCode. Будущие обновления появляются в приложении после публикации нового выпуска; проверка не выполняется постоянно в фоне.

Автотесты проверяют логику и интерфейс через Robolectric. Установка системным установщиком и работа сети на конкретном телевизоре требуют проверки на устройстве.
