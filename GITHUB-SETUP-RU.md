# Проверки GitHub и Codex

## Что настроено в репозитории

- Исходники приложения 0.5.0 с прежним app ID.
- Workflow `Android checks`: push в main, pull request и ручной запуск.
- JDK 17, Android SDK 36, сборка, unit-тесты и Android lint.
- Отчёты тестов/lint сохраняются на 7 дней; сборочный APK не распространяется.
- AGENTS.md с правилами независимого ревью, совместимости, управления пультом и HTTPS.
- Закрытый ключ подписи не входит в репозиторий. Обычная сборка требует прежний ключ; явный CI-флаг разрешает только тестовую подпись.

## Включение автоматического ИИ-ревью

Доступ к GitHub и Automatic review — разные настройки. Наличие подключения само по себе не подтверждает включение ревью.

1. В настройках Codex открой раздел Code review / Review code.
2. Выбери `Sqzzzzzzz/utv-android-tv`.
3. Включи Automatic review. Если используется Follow personal preferences, включи Automatic review также в Personal preferences.
4. Выбери Review trigger, включающий обновления pull request, чтобы новые коммиты тоже проверялись.
5. Открой pull request и проверь, что Codex опубликовал ревью.

Разовый запуск: комментарий `@codex review` в pull request. Подключение и лимиты проверяются в твоём аккаунте; настройку Automatic review нельзя включить файлом workflow.

## Исправление замечаний

Встроенное ревью оставляет замечания. Для исправления в той же ветке можно дать Codex поручение в комментарии, например `@codex fix the CI failures` или попросить устранить конкретную найденную ошибку. После исправления проверяй новый запуск Android checks.

Полностью автоматический цикл исправлений через OpenAI API **не настроен**. Для него потребуется отдельный API-ключ и выбранные пользователем ограничения расходов. Текущий workflow не вызывает OpenAI API и не требует API-ключей.

## Работа с изменениями

Изменения делаются в отдельной ветке и оформляются pull request. Перед объединением дождись успешного Android checks и изучи замечания ИИ. При желании в GitHub Settings → Rules можно дополнительно сделать проверку обязательной, если это доступно на твоём тарифе для приватного репозитория.

Проверки выполняются на GitHub Actions и зависят от доступных минут/лимитов аккаунта.

## Подтверждённая проверка настройки

29 октября 2026 года проверен запуск [Android checks](https://github.com/Sqzzzzzzz/utv-android-tv/actions/runs/40862807844): 82 теста прошли, один необязательный тест пропущен, ошибок lint нет, предупреждений — 47.

После обновления GitHub Actions до поддерживаемых версий Node 24 [повторная сборка](https://github.com/Sqzzzzzzz/utv-android-tv/actions/runs/40863553494) также завершилась успешно. [Ревью Codex](https://github.com/Sqzzzzzzz/utv-android-tv/pull/2#issuecomment-6495148401) не выявило серьёзных проблем.

Эти результаты подтверждают проверку конкретных коммитов. Для нового pull request проверяй свежий запуск Android checks и поле Review trigger в ответе Codex: оно показывает, запущено ли ревью автоматически или вручную.
