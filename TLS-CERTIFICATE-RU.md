# Сертификат для HTTPS-совместимости

В приложение включён один публичный CA: GlobalSign Root R46. Это не сертификат конкретной серии или закрытый ключ.

Источник: https://support.globalsign.com/ca-certificates/globalsign-root-certificates

Официальный документ с SHA-256: https://www.globalsign.com/en/repository/GlobalSign-CPS-v10.8.pdf

Файл приложения: app/src/main/res/raw/globalsign_root_r46.pem

SHA-256 DER:

```text
4fa3126d8d3a11d1c4855a4f807cbad6cf919d3a5a88b03bea2c6372d93c40c9
```

Имя: C=BE, O=GlobalSign nv-sa, CN=GlobalSign Root R46. Срок: 20.03.2019–20.03.2046. Проверены отпечаток, CA Basic Constraints и собственная подпись.

Причина: пользователь прислал диагностику Android 12 / API 31 с Trust anchor for certification path not found. Свежая внешняя проверка TLS сервера www.u-tv.ru с SNI показала цепочку *.u-tv.ru → GlobalSign GCC R46 DV TLS CA 2025 → GlobalSign Root R46. Цепочка сервера полная; на устройстве не удаётся построить доверие до корня. Это не основание считать, что R46 отсутствует на всех устройствах Android 12: речь о совместимости конкретного хранилища ТВ.

В XML дополнительный корень разрешён только для трёх точных имён: u-tv.ru, www.u-tv.ru, img.u-tv.ru. Поддомены автоматически не включаются. Системные корни сохранены. Для остальных имён дополнительных CA нет. Подлинность сервера и сроки проверяет Android; произвольные и просроченные сертификаты не разрешены. Сертификат не устанавливается в систему ТВ.

Офлайн-фикстуры теста — публичные подписанные сертификаты сервера и промежуточного CA из проверки SSL Labs на 28.10.2026. SHA-256:

- Сервер: 6177e9d4ec082fc3014258a77ea28043c03622c63d22e9482eebdda2cfafe7c0
- Промежуточный CA: b59410f367b986e98e53a9789a6580553a74be515211d9f6ecb6e8a11e83aeaa

Источник фикстур: https://api.ssllabs.com/api/v3/analyze?host=www.u-tv.ru&fromCache=on&all=done

Результат SSL Labs использовался для получения цепочки; каждая подпись дополнительно проверена офлайн до официального CA. Прокси-сертификаты среды разработки не включены. Тесты используют фиксированную дату 28.10.2026, а реальное приложение — текущее время устройства.

Видеосервер cdn.media1.ru проверен отдельно: передаёт цепочку Let’s Encrypt до ISRG Root X1. Для него дополнительное доверие GlobalSign не включается; используется системное доверие.
