# Ю — прототип 0.5.0

Неофициальный личный клиент для Android TV / Google TV. Поддерживает шоу «Мама в 16» и «Маменькин сынок» с u-tv.ru. Подходит для проверки на TCL 55P8K; необходим Android TV 8.0 или новее и интернет.

## Возможности

- Получение актуального списка сезонов и серий со страниц сайта.
- Крупные карточки выпусков и заметная рамка выбранного элемента.
- Управление стрелками, OK, кнопкой «Назад» и медиакнопками пульта.
- Видеоплеер Media3 / ExoPlayer с автоматическим выбором качества доступного потока.
- Сохранение позиции каждые 5 секунд и при уходе с экрана воспроизведения.
- Кнопка «Продолжить», переход к следующему выпуску после окончания серии.
- Сохранённый каталог при отсутствии сети. Для просмотра видео интернет необходим.

Видео и обложки загружаются с серверов сайта; видеофайлы не включены в APK. Приложение не использует аккаунты и не отправляет историю просмотра на собственный сервер.

## Установка APK на телевизор

Файл для установки: `utv-0.5.0.apk`.

1. Скопируй APK на USB-флешку и подключи её к телевизору.
2. Открой файл файловым менеджером на телевизоре. Если менеджера нет, сначала потребуется установить его из Google Play.
3. При запросе Android разреши установку из этого файлового менеджера и повторно открой APK.
4. Установи приложение. Найди «Ю» в списке приложений телевизора.
5. После установки можно убрать разрешение файлового менеджера на установку приложений.

Точное расположение разрешения зависит от версии прошивки TCL. Обычно оно находится в настройках приложений, в специальном доступе / установке неизвестных приложений.

### Установка через компьютер

Если на телевизоре уже настроена отладка по сети и он подключён к ADB:

```text
adb install -r utv-0.5.0.apk
adb shell am start -n dev.mark.utvremote/.ShowSelectionActivity
```

Если телевизор предлагает беспроводное сопряжение ADB, сначала используй `adb pair` с адресом и кодом, указанными на экране, а затем `adb connect` с адресом подключения. Порт сопряжения может отличаться от порта подключения. На прошивках с обычной отладкой по сети используй тот адрес и порт, которые доступны на телевизоре.

## Пульт

В каталоге стрелки перемещают выделение. OK на сезоне открывает его серии; OK на серии запускает просмотр. Из первого ряда серий стрелка вверх возвращает к сезонам. «Назад» из плеера возвращает в каталог.

Когда панель плеера скрыта, OK включает паузу / продолжает просмотр, а стрелки влево и вправо перематывают на 10 секунд и показывают панель. На видимой панели стрелками выбираются кнопки и шкала времени; на шкале можно перематывать видео. Панель автоматически скрывается. Качество видео выбирается автоматически в пределах вариантов, доступных у выпуска.

## Исходники и сборка

Проект открывается в Android Studio. Требуются JDK 17 и Android SDK Platform 36 / Build Tools 36.0.0. Gradle Wrapper включён в архив.

Windows:

```text
gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Linux / macOS:

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

В `signing/prototype-debug.keystore` сохранён стандартный тестовый ключ этой сборки с паролями `android`. Он нужен, чтобы следующие личные тестовые APK можно было устанавливать поверх этой версии с сохранением данных. Для публикации приложения потребуется отдельный закрытый ключ релиза.

## Диагностика и исправления 0.1.6

Позиция просмотра сохраняется также во время буферизации и после ошибки плеера, перед повторной попыткой и освобождением плеера. Перемотка назад перед ошибкой больше не возвращает к более поздней сохранённой позиции. Пауза в последних секундах не считается окончанием выпуска.

Состояние паузы и экран завершения восстанавливаются после пересоздания Activity. Возврат из главного меню телевизора к уже законченному выпуску оставляет экран завершения; «Смотреть сначала» заново получает поток и начинает с нуля. При паузе и уходе из приложения снимается запрет на заставку. Плееру включено штатное управление аудиофокусом Media3. Отступ для нижней подсказки перенесён на панель управления, поэтому он больше не уменьшает видео. Подсказки меняются для окон загрузки, ошибки и завершения.

При обновлении каталога сохраняется выделенная серия или сезон. Неудачная фоновая загрузка сохранённого каталога не забирает выделение. Стрелка вниз из третьей колонки теперь попадает на ближайшую карточку неполного последнего ряда. В окнах загрузки, ошибки и завершения фокус пульта остаётся на доступных кнопках.

UI-тесты работают без сети; отдельно проверены все 73 страницы выпусков и все 72 встроенных HLS-плейлиста. Два коротких фрагмента, по одному из каждого шоу, прошли программное декодирование. Подробности и ограничения проверки — в `VERIFICATION-RU.md`.


## Новые функции 0.2.0

На главном экране под каждым шоу появилась кнопка «Продолжить». Если последний выпуск отмечен просмотренным, кнопка предлагает следующий непросмотренный выпуск из сохранённого каталога. Когда таких выпусков больше нет, кнопка скрывается.

На карточках показываются прогресс, «Просмотрено» и «Новая серия». Удерживай OK или нажми Menu на карточке, чтобы вручную поставить или снять отметку. Обычное нажатие OK сразу запускает просмотр. После настоящего окончания выпуск отмечается просмотренным автоматически. При повторном просмотре отметка снимается после готовности плеера. Прогресс рассчитывается по фактической длительности потока, а до её получения — приблизительно по длительности с сайта.

При первом запуске каталог становится исходным списком без массовых меток «Новая серия». После установки поверх старого APK исходным списком служит прежний сохранённый каталог. Затем новые адреса выпусков помечаются при открытии шоу или нажатии «Обновить каталог». Метка сохраняется до успешной подготовки воспроизведения или ручной отметки просмотра. Неудачный запуск, включая выпуск на Иви, её не снимает. Фоновой проверки сайта при закрытом приложении нет.

В «Настройках» выбираются предпочтительное качество (Авто / 1080p / 720p / 480p), автопереход и задержка 5 / 10 / 15 / 30 секунд. По умолчанию сохранено прежнее поведение: переход по кнопке, качество Авто. Во время видео кнопка «Качество» или Menu предлагает реальные поддерживаемые дорожки этого выпуска. Если предпочтительного разрешения нет, выбирается ближайшее ниже; если ниже нет — минимальное поддерживаемое. В плеере показан доступный вариант, например 468p вместо предпочтительных 480p.

Автопереход запускается после окончания выпуска. Любое нажатие пульта или кнопка отмены останавливают отсчёт. Уход из просмотра также отменяет его; возвращение из меню телевизора не запускает отменённый переход повторно. Таймер использует монотонный срок окончания, чтобы задержки интерфейса не накапливались.

### Обновление приложения из настроек

«Установить обновление из APK» открывает системный выбор файла: можно указать APK на флешке или в загрузках. Доступность выбора зависит от наличия системного файлового интерфейса на телевизоре. Перед установкой проверяются пакет, увеличение versionCode и совпадение подписи с установленным приложением. Затем Android запрашивает разрешение на установку и подтверждение обновления. Удаление приложения не требуется.

Для поиска новых версий нужен постоянный HTTPS-источник релизов. Он **пока не подключён**: приложение не опубликовано на сервере обновлений. Адрес можно задать в «Источник обновлений». Формат JSON:

```json
{
  "versionCode": 17,
  "versionName": "0.5.0",
  "apkUrl": "https://YOUR_HOST/utv-0.5.0.apk",
  "sha256": "SHA256_ЭТОГО_APK_64_HEX_СИМВОЛА",
  "notes": "Описание изменений"
}
```

Это шаблон, а не действующий адрес релизов. Для следующей версии нужно разместить APK с тем же сертификатом, посчитать его SHA-256 и загрузить JSON. После подключения источника кнопка проверки показывает доступную версию, а отдельная кнопка скачивает и передаёт её системному установщику. HTTPS проверяется для всех перенаправлений; размер JSON ограничен 64 КиБ, APK — 50 МиБ; скачанный APK сверяется с SHA-256. Обновления запускаются вручную.

Для передачи APK установщику добавлен AndroidX Core 1.17.0 / FileProvider (Apache License 2.0). Провайдер закрыт для общего доступа и временно передаёт доступ только к каталогу кэша обновлений. История просмотра через него не доступна. Разрешение REQUEST_INSTALL_PACKAGES используется при выбранной пользователем установке обновления.


## Загрузка и диагностика 0.2.1

HTML загружается стандартным HttpURLConnection / HTTPS Android с обычными заголовками HTML-клиента. Jsoup используется для разбора HTML. Добавлены явная обработка gzip, ограничение распакованного ответа 3 МиБ, проверка HTTPS и разрешённых хостов на каждом перенаправлении, закрытие соединений при ошибках и запрет устаревшего HTTP-кэша. Заголовок User-Agent согласован для страниц, обложек и видеопотоков. Проверка сертификатов не отключалась.

Ошибки DNS, HTTPS/TLS, тайм-аута, HTTP и формата каталога различаются. При пустом каталоге код виден в подзаголовке, а подробности — в «Настройки → Диагностика загрузки». То же окно можно открыть удержанием OK на кнопке «Обновить каталог». Запись содержит этап, код, версию приложения, Android, время телевизора и сообщения исключений. Эти сведения хранятся локально и автоматически никуда не отправляются.

Эта сборка подготовлена после сообщения о пустом каталоге на физическом TCL. По фотографии версии 0.2.0 точная причина не устанавливается: прежний интерфейс скрывал исключение. Поэтому до проверки 0.2.1 на том же устройстве нельзя утверждать, что причина устранена. Если сбой повторится, нужна фотография окна диагностики. Старое сообщение, безосновательно предлагающее проверять общий интернет при любой ошибке, убрано.


## Совместимость HTTPS 0.2.2

По диагностике физического TCL с Android 12 подтверждён SSLHandshakeException / Trust anchor not found. Текущая цепочка www.u-tv.ru завершается на GlobalSign Root R46. В APK включён официальный публичный сертификат этого центра. Android Network Security Configuration дополняет им системное доверие только для u-tv.ru, www.u-tv.ru и img.u-tv.ru. Все прочие адреса, включая произвольный источник обновлений, используют обычное системное доверие.

Проверка HTTPS, имени сервера и сертификатов остаётся стандартной. Не используются trust-all, отключение HostnameVerifier, разрешение HTTP или доверие ко всем пользовательским сертификатам. Системное хранилище телевизора не меняется. Корневой сертификат и его происхождение описаны в TLS-CERTIFICATE-RU.md.

На Android API 31 проверена загрузка доменной конфигурации из Manifest. Реальная подписанная цепочка сайта используется как офлайн-фикстура: с другим корнем она не проходит, с R46 проходит; просроченный серверный сертификат отклоняется. Это проверка причины и механизма исправления, но запуск нового APK на конкретном TCL подтверждает пользователь.

## Чёткие превью 0.2.3

Карточки используют опубликованные сайтом варианты изображений из picture/srcset до 1200×672 вместо img/src 300×168. Дополнительное уменьшение при декодировании убрано (раньше получалось 150×84). Подписанные адреса сайта сохраняются без изменения. Старый сохранённый каталог обновляется при открытии шоу; если сеть недоступна, сохраняется прежнее превью. При необходимости нажми «Обновить каталог».

## Новый плеер 0.3.0

- OK на видео — пауза / продолжение. На кнопке — выполнение её действия.
- ← / → на видео — выбор момента ±10 секунд; удержание ускоряет шаг до 30 и 60 секунд. Основное видео ставится на паузу, фактическая перемотка происходит один раз после OK. «Назад» отменяет выбор и восстанавливает прежнее состояние воспроизведения.
- Во время выбора видны исходное и выбранное время. После остановки стрелок на 400 мс появляется беззвучный кадр из видеопотока с предпочтением 720p. Маленькие спрайты сайта 100×56 не используются. Картинка ниже 720p не показывается.
- HD-кадр требует дополнительного аппаратного декодера и скачивания короткого участка видео. При недоступности декодера/сети остаётся выбор по времени с сообщением «Кадр недоступен»; основное видео не перематывается до подтверждения. Окно освобождает декодер при отмене, подтверждении и уходе с экрана.
- ↓ открывает нижние кнопки, ↑ возвращает фокус на видео. Панель: «Пауза / Продолжить», «С начала», «Предыдущая», «Следующая», «Качество», «Серии». Кнопки переходов появляются при наличии соответствующей серии.
- «Серии» открывает список поверх текущего просмотра; отмечен текущий выпуск, доступен выбор только того же шоу.
- «Назад» сначала отменяет перемотку / закрывает диалог / скрывает панель; из чистого экрана возвращает в каталог.
- Панель скрывается через 4 секунды просмотра; остаётся при паузе и выборе момента. Menu открывает качество. Медиакнопки Play/Pause/Rewind/FastForward поддерживаются.
- Сохранены история, настройки качества, ручной и автоматический переходы, диагностические сообщения, исправление TLS и чёткие обложки.

Новый плеер и HD-кадры требуют проверки на физическом TCL; Robolectric не подтверждает работу аппаратного видеодекодера конкретного телевизора.

## Оригинальные обложки 0.3.1

Некоторые картинки в srcset сайта даже при 1200×672 содержат увеличенное размытое изображение. Теперь после обычного превью приложение получает оригинальную обложку из og:image видеоплеера соответствующего выпуска. В проверенных выпусках обоих шоу это PNG 1600×900 с более чёткими деталями и надписями. Первая загрузка оригиналов происходит постепенно в фоне; уже доступное превью не пропадает.

Оригиналы сохраняются в кэше приложения на 7 дней (до 64 МиБ). В оперативной памяти картинка подгоняется под физический размер ТВ-карточки без увеличения, а не хранится целиком для всех серий. Переход на другой сезон отменяет очереди старого сезона. Если плеер, оригинал или сеть недоступны, сохраняется обычная обложка. Для выпусков на Иви без Media1-плеера также остаётся обычное превью. Фактическая детализация зависит от опубликованного источником оригинала; отсутствующие детали не дорисовываются.

Размер загрузки ограничен 8 МиБ на файл, декодирование — по размерам изображения; после декодирования не более 1920×1080. Каждый HTTPS-редирект проверяется. Разрешены img.u-tv.ru и только путь оригинальных обложек на cdn.media1.ru. Проверка TLS сохранена. Новый плеер 0.3.0 не изменён.

## Главный экран «Кинотеатр» 0.4.0

Выбран второй визуальный вариант: крупная фоновая заставка, название и возраст, одна кнопка «Продолжить»/«Смотреть», две карточки выбора внизу. При фокусе на карточке меняется выбранное шоу; вверх открывает главную кнопку, ещё вверх — настройки. Вниз возвращает к карточке именно выбранного шоу. OK выполняет действие один раз при отпускании, уход в меню ТВ отменяет незавершённое нажатие.

Если у шоу нет истории, «Смотреть» открывает каталог. При наличии доступного продолжения кнопка сразу запускает соответствующую серию этого шоу. После возврата из плеера подпись и позиция обновляются без сброса фокуса. История и настройки прежних версий совместимы.

Фоновые hero_mama.png / hero_mamenkin.png художественно подготовлены встроенным imagegen на основе прежних обложек для выбранного дизайна. Это оформительские заставки. Они встроены в APK и работают без интернета. Каталог серий использует прежние оригинальные обложки источника, функции плеера и TLS сохранены.

## Плеер по выбранному макету 0.5.0

Нативная нижняя панель: белая шкала с малиновым маркером, время слева и длительность справа, круглая кнопка пуска/паузы, кнопки ±10 с, «Серии» слева и «Качество» справа. Название и номер выпуска вверху на полупрозрачном градиенте. Видео занимает весь экран; фон макета в APK не включён и не подменяет реальное видео.

При перемотке превью кадра с подписью времени движется над маркером шкалы. Положение ограничено краями экрана, указатель остаётся направленным на точку перемотки. Загружаются реальные кадры 720p, если они доступны источнику и аппаратному декодеру ТВ. При быстром удержании стрелки запрос ждёт короткой остановки; при ошибке остаётся выбор по времени. После отмены можно повторить попытку загрузки кадра.

На видео ←/→ выбирают момент; удержание ускоряет шаг. OK подтверждает один переход, Назад отменяет выбор. Вниз переводит фокус к кнопкам; вверх возвращает на видео. Кнопки ±10 с тоже сначала показывают выбранный момент. Menu открывает дополнительные действия: качество, с начала, предыдущая/следующая серии при наличии, список серий. Они сохраняют функции прежнего плеера, не перегружая панель.

Исправлены прерванное нажатие OK после ухода в меню ТВ и состояние вложенного диалога качества после дополнительного меню. Проверены отмена перемотки, история, пауза после Home, качество, автопереход, границы превью. Тесты не заменяют проверку дополнительного аппаратного декодера на конкретном TCL.

Дополнительное меню доступно также вторым нажатием ↓, когда фокус уже на нижних кнопках. Физическая кнопка Menu на пульте не обязательна.
